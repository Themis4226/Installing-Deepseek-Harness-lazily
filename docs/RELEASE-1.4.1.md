# DSH Desktop Launcher 1.4.1 (Preview)

一款基于DeepSeek Harness(DSH)的启动器。非官方 Windows x64 社区启动器。

## 本次更新

- 初始 DSH 运行时升级为官方 npm `@deepseek-ai/dsh@0.1.2-rc.1`，依赖在独立目录重新安装和锁定，没有修改官方运行时代码。
- 适配新版 DSH 的本机认证启动链接：使用官方 token 换取 HttpOnly Cookie 后进入首页，保留认证保护，日志不记录启动 token。
- 启动链接只接受固定的 `127.0.0.1` 来源，并等待完整输出行；健康检查支持官方认证跳转。
- 保留“软件更新”和维护者专用的“官方更新检查”插件；图标、右上角关闭行为及进程隔离保持不变。

## 下载和升级

- **Full package / Windows x64**：`DSH-Desktop-Lite-1.4.1-win-x64.zip`，完整解压后运行 `DeepSeek Harness.exe`。需要另有受支持的 x64 Node.js 和 WebView2 Runtime。
- **已有 1.4.0**：通过“设置 → 通用设置 → 软件更新 → 检查更新”，确认后一起下载 EXE 和运行时，验证并重启。启动失败时自动恢复旧 EXE 和旧运行时。
- **1.3.0 及更早版本**：请完整下载并解压一次，不能只复制新版 EXE。
- 单独的 EXE 和 runtime ZIP 是更新器资源，不是第一次安装所需的完整包。

DSH `0.1.2-rc.1` 的这套桌面集成要求启动器至少为 **1.4.1**。更新源会设置该门槛，避免旧启动器只收到不兼容的运行时。

升级前建议备份 `%USERPROFILE%\.dsh`。官方本次移除了可选的 SQLite 会话持久化后端；曾使用该后端的用户应先用旧版导出会话。第三方插件可能需要适配。本次没有把维护者的私有配置或官方更新检查插件加入公开 Lite 包。

[官方发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.2-rc.1)

## 验证范围

- Windows 上 Node.js 24.19.0、25.8.0 的更新器和两套插件测试各 37 项通过；新测试还在旧运行时 `0.1.1-rc.2` 上通过，验证向后兼容。

- 真实 WebView2：新认证跳转、页面加载、软件更新入口；未认证首页仍返回 401。
- 用本机模拟模型完成实际文件写入、读取和 PowerShell 工具调用；没有使用真实 API Key，没有产生付费模型请求。
- 从公开 1.4.0 完整 ZIP 验证成对升级至本版本；另用隔离故障运行时验证回退后旧 EXE 的哈希、旧运行时状态及旧版页面恢复。
- 正常关闭和强制终止测试启动器时，其 DSH 子进程退出；独立的 Node.js 对照进程仍运行。
- 最终 ZIP 独立解压复核，24451 个文件；未包含测试故障包、私有用户路径或维护者专用插件。

上述测试不能覆盖每台用户电脑、所有第三方插件或真实模型服务的全部行为。两个项目仍是预览版本。
